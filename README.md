# Rock Paper Scissors Brawl

돌·종이·가위가 서로 쫓고 먹으며 한 종류만 남을 때까지 싸우는 자동 대난투 시뮬레이션입니다. 구경만 하는 게임입니다.

- 주소: https://dobbi52.github.io/rps-brawl/
- 파일 하나(`index.html`)로 되어 있습니다.
- 시작 숫자(종류마다 0~150)와 배속(1x·2x·4x)을 고를 수 있습니다.
- 경기장: 네모(Square)·도넛(Donut)·모래시계(Hourglass)·무작위(Random) 중에서 고릅니다.
- 장애물: 기둥(Pillars)·회전 막대(Spinner, 무리를 쓸어냄)·순간이동 구멍(Portals, 대각선 귀퉁이끼리 이어짐)을 켜고 끌 수 있습니다.
- 원본은 Claude 아티팩트 파일(`rps-battle.html`)이고, `index.html`은 그 앞뒤에 `<head>`와 숨김(`[hidden]`) 규칙만 덧붙인 것입니다.
- 구글 로그인과 기록 저장은 붙이지 않습니다. 사용자가 이 게임은 로그인 없이 올리기로 정했습니다.
